# Manufacture PWA

A modern Progressive Web Application (PWA) for manufacturing product management and ordering system. Built with React, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Product Selection System**: Interactive forms for selecting countries, harbors, and products
- **Real-time Data Fetching**: Dynamic loading of countries, harbors, and products based on selections
- **Product Summary**: Comprehensive order summary with pricing calculations
- **Responsive Design**: Mobile-first design that works across all devices
- **Progressive Web App**: Installable app with offline capabilities
- **Modern UI Components**: Built with Radix UI and styled with Tailwind CSS
- **Form Validation**: Robust form handling with React Hook Form and Zod
- **State Management**: Efficient state management with Zustand

## 🛠️ Tech Stack

### Frontend

- **React 18** - Modern React with hooks and concurrent features
- **TypeScript** - Type-safe development
- **Vite** - Fast build tool and development server
- **Tailwind CSS 4** - Utility-first CSS framework

### UI Components

- **Radix UI** - Accessible, unstyled UI primitives
- **Lucide React** - Beautiful & consistent icons
- **Class Variance Authority** - Component variant management
- **CMDK** - Command palette component

### State & Data Management

- **Zustand** - Lightweight state management
- **TanStack Query** - Powerful data synchronization
- **React Hook Form** - Performant forms with easy validation
- **Zod** - TypeScript-first schema validation

### PWA & Performance

- **Vite PWA Plugin** - PWA capabilities
- **Workbox** - Service worker management
- **React Number Format** - Number input formatting
